WARP → AmneziaVPN

Создаёт обычный WireGuard-профиль Cloudflare WARP, который можно импортировать в AmneziaVPN.

Важно: это WireGuard-конфиг для AmneziaVPN, а не AmneziaWG. Приватный ключ создаётся локально в браузере и никуда не отправляется.

Если браузерный режим не сработал

Открой вкладку Actions репозитория → Generate WARP config → Run workflow. GitHub сам создаст конфиг и положит его в artifact.
