WARP → AmneziaVPN

Генерирует обычный WireGuard-профиль Cloudflare WARP для импорта в AmneziaVPN.

Почему через Actions: Cloudflare WARP API не разрешает прямую регистрацию из GitHub Pages из-за CORS, а публичные CORS-прокси нестабильны. Поэтому генерация выполняется на бесплатном GitHub runner без стороннего proxy.
Надёжный режим

Создать WARP config

Нажми кнопку ниже. На странице GitHub нажми Run workflow, выбери параметры и запусти генерацию.

После запуска: дождись зелёной галочки → открой выполненный запуск → внизу страницы скачай artifact warp-amnezia-config → распакуй warp-amnezia.conf → импортируй его в AmneziaVPN как WireGuard.

Что можно выбрать

Routing mode: IPv4 + IPv6 или только IPv4. DNS: Cloudflare, Quad9 или Google. Также можно изменить MTU и PersistentKeepalive.

Безопасность

Приватный WireGuard-ключ создаётся только внутри временного GitHub runner. Он попадает в artifact на 1 день и не коммитится в репозиторий. Не публикуй скачанный .conf.

Это WireGuard-конфиг для использования в AmneziaVPN, а не AmneziaWG. Проект не аффилирован с Cloudflare, WireGuard или Amnezia.
