WARP → AmneziaVPN

Создаёт WireGuard-профиль Cloudflare WARP и скачивает .conf прямо на сайте — без перехода в GitHub Actions.

Приватный ключ остаётся в браузере. Worker получает только публичный WireGuard-ключ и регистрирует устройство в WARP.
Этот адрес нужен только один раз и сохраняется локально в браузере. Код Worker уже лежит в репозитории: worker/src/index.js.

Worker ещё не создан?

Открой Cloudflare → Workers & Pages → Create Worker → вставь код из worker/src/index.js → Deploy. Затем вставь адрес *.workers.dev выше. После этого генерация полностью происходит с этой страницы.

Неофициальный open-source инструмент. Это обычный WireGuard-профиль WARP, а не AmneziaWG.
