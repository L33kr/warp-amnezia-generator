WARP → AmneziaVPN

Создаёт WireGuard-профиль Cloudflare WARP и скачивает .conf прямо на сайте.

Приватный WireGuard-ключ остаётся в браузере. Сервер Deno получает только публичный ключ, регистрирует устройство в WARP и возвращает публичные параметры подключения.

Как это работает

Страница и API работают в одном приложении Deno Deploy. Браузер создаёт WireGuard-ключи локально → /api/register регистрирует публичный ключ в WARP → браузер собирает и скачивает готовый конфиг. Никаких CORS proxy и GitHub Actions для обычной генерации.

Неофициальный open-source инструмент. Это обычный WireGuard-профиль WARP, а не AmneziaWG.
